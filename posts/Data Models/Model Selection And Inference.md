# Data Model Selection And Inference 模型选择和推理使用的信息理论方法

## 前言

本书的目的：向研究生和各个科学学科的研究人员介绍信息论方法在经验数据分析中使用。

信息论允许基于多个模型进行推理(包括无条件精度的估计)；在其初始形式中，它对于选择"最佳"模型并对其余模型进行排名非常有用。

数据分析中的关键问题通常是**选择一个最好的近似模型，该模型最能代表数据支持的推论(估计的“最佳近似模型”）**

**赤池信息准则**——Kullback-Leibler距离的估计量。为经验数据分析中的模型选择提供了新的范式。

将建模经验视为经验数据中可解释信息的近似练习，其中数据时来自某些明确定义的总体或者过程样本。选择最佳近似模型代表了数据的推论，并且告诉我们数据可以支持什么“效果”（由参数所展示)。在该书中将重点关注Akaike的信息准则(以及各种扩展)。后面的章节提供了正式的方法来促进从一组先验的模型中进行推理，并提供在不以特定模型为条件的情况下的估计不确定性的方法。

基于信息论的模型选择代表了统计科学中的一种完全不通的方法，并且最终选择的模型可能与基于某种形式的统计假设检验的模型选择有很大的不同。

使用信息论方法来“观察研究”的数据。对于信息论方法来说，其并不是对于所有的情况都是最好的。它们缺失代表了一种统一而严格的理论，是似然理论的眼神，是信息论的重要应用，并且是客观且实用的，可以应用于非常广泛的经验问题。通过基于Kullback-Leibler距离的方法

本书的目的是提出并说明一种一致的方法，在令人信服的通用框架下以统一的方式处理模型判定、模型选择、模型参数估计及其不确定性。我们回顾并且解释了其他信息标准，并提出了几种估计模型选择不要确定性纳入精度估计的新方法。给出了一系列示例来说明各种技术问题。

预备知识：读者应该在定量科学方面有一定的成熟度，并具有数据分析的经验。

## 术语表

下面给出了常用的符号和缩写，具体示例的特殊符号可以在这些部分中找到

|     术语     |                             名称                             |
| :----------: | :----------------------------------------------------------: |
|     AIC      |                        Akaike信息准则                        |
|   $AIC_k$    | 在任何一组模型中(给定数据生成上下文)，一个是模型预期的Kullback-Leibler，引起AIC是最佳模型。我们通常让$k$索引最佳模型(重要的是概念，而非具体索引)。真正的最佳模型类似于给定模型的未知参数的真实值。对于实际数据，$k$未知，因此即使已知$AIC_i$值集，也无法识别$AIC_k$。**必须清楚的是，这个“最佳模型$k$”是所有可能样本(其中我们只有一个样本)的相同模型** |
|   $AIC_c$    |          二阶AIC，对于小的样本数据来说是十分必要的           |
| Akaike  权重 | 在给定数据的情况下对模型的可能性进行估计。上述估计会被标准化为总和1，并用$W_i$所表示 |
|     Bias     |           （估计器)$Bias=E(\widehat\theta)-\theta$           |
